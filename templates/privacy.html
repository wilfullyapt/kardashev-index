Privacy

We collect as little as we can.

There are no accounts for visitors, no analytics, no advertising and no tracking cookies.

Cookies

The site sets one cookie, session, and only for site administrators after they sign in. It is signed and HTTP-only, contains only the admin’s sign-in state, and expires after a limited time. Ordinary visitors get no cookies from us.

What you submit

Suggest an entity stores the name and optional website you enter, and the time. We don’t ask for your name or email. To limit abuse, your IP address is kept in server memory to count submissions per hour; it is never written to the database and is discarded when the service restarts.

Corrections sent by email are used only to investigate and fix the issue.

Service providers

  • 01Hosting. The site runs on Render, which (like any web host) keeps standard request logs — IP address, time, page requested, browser user agent — for operating and securing the service.
  • 02Fonts. Pages load web fonts from Google Fonts, so your browser contacts Google’s servers, which receive your IP address and user agent. See Google’s privacy policy.
  • 03AI model. Research and scoring send public company information to xAI’s API. No visitor data is sent to it.
